📙 Часть 3: Сортировка и поиск

1. In the basic Bubble Sort shown in the lecture, what is the main reason the last unsorted position becomes correct after one full outer pass?
→ Larger adjacent values gradually move to the right
2. Which description best matches the repeated phase of Heap Sort?
→ Swap root, shrink active area, restore order
3. A student builds the heap correctly but does not reduce the active heap size after swapping the root with the last element. What is the likely issue?
→ Sorted elements may be pulled back into later heap operations
4. Which pair of properties correctly matches the search methods in the lecture?
→ Linear: unsorted allowed; Binary: sorted required
5. In Binary Search, the middle value is greater than the target. Which part can be ignored in an ascending array?
→ The upper half
6. Which case most naturally leads Quick Sort toward its worst-case behavior?
→ Pivot is repeatedly an extreme value
7. Which statement best distinguishes Heap Sort from Merge Sort in terms of how it organizes work?
→ It maintains a priority-like tree structure
8. Which feature is most important when deciding whether Binary Search can be applied directly?
→ The array is already sorted
9. An implementation of Bubble Sort compares adjacent elements and swaps only when they are in the wrong order. Which input would cause many comparisons but no swaps?
→ A list already sorted in the target order
10. Which conclusion best reflects the lecture's overall message about searching choices?
→ The best method depends on order, preprocessing cost, and number of searches
11. During an ascending Bubble Sort pass, the pair [7, 3] is encountered. What local action is consistent with the algorithm?
→ Swap the two adjacent values
12. Why is Binary Search usually faster than Linear Search on large sorted arrays?
→ It removes about half of the remaining candidates each step
13. After a correct Quick Sort partition around a pivot, what should be true?
→ Values are separated relative to the pivot
14. Which stopping idea is shared by Merge Sort and Quick Sort in the lecture?
→ Continue until subproblems become atomic
15. Which condition is enough for a sequence to be considered sorted in the Merge Sort explanation?
→ Its length is exactly one
16. Which mistake would most directly break the merge step?
→ Forgetting to copy remaining values from one side
17. For repeated membership queries on changing data, what is a reasonable advantage of hashing over Binary Search on an array?
→ It can avoid maintaining global sorted order
18. What makes an algorithm a divide-and-conquer algorithm?
→ It reduces a problem to similar smaller problems
19. Which statement best contrasts Merge Sort and Quick Sort?
→ Merge Sort organizes work through merging; Quick Sort through partitioning
20. Which situation most strongly favors Binary Search?
→ The data is sorted and many lookups are needed
21. What causes hash table search to approach O(N) in the worst case?
→ Too many values collide into the same place
22. Why can choosing the last element as pivot be risky on already sorted input?
→ The pivot may repeatedly create very uneven partitions
23. A hash table has a poor hash method that maps many different keys to one chain. What is the likely result?
→ Lookups may require scanning much of that chain
24. Why does Merge Sort continue dividing until subarrays have one element?
→ Single-element arrays can be treated as already ordered
25. Which comparison between Bubble Sort and Merge Sort is most accurate?
→ One scans locally; the other splits and recombines

→ Distance, approximate time, average speed, or a combination of these
2. Which combination of actions best matches the 10 lecture's steps to design DP?

3. What condition must be satisfied before creating an edge between A and B?
→ Both vertices A and B must exist
4. What is the general idea of dynamic programming according to the lecture 10?
→ Solving complex problems by breaking them down into simpler subproblems
5. How does the lecture 8 describe the overall adjacency-list representation of a graph?
→ An array of n adjacency lists
6. How does the lecture 10 describe dynamic programming in relation to inefficient recursion?

→ An acyclic connected graph
9. How does the lecture 10 characterize divide-and-conquer algorithms in terms of direction?
→ They can be thought of as top-down algorithms
10. How does BFS process nodes from the current level?
→ It visits all unvisited neighbors of each node in the order the level nodes were visited
11. How is the length of a path or cycle measured?
→ By the number of edges
12. Which data structure is used when implementing BFS?
→ Queue
13. Why does the lecture 9 introduce graph search as an important topic?

15. What does the 10 lecture's formula-like summary suggest about dynamic programming?
→ DP combines a recursive solution with memoization or a bottom-up approach
16. What property must the shortest path from vertex A to vertex E have in an edge-weighted digraph?

17. Why does the lecture 9 say Dijkstra's algorithm requires positive weights?
→ Because edge weights are added when calculating paths
18. What does an edge weight represent in the 8 lecture's driving-distance example?
→ Driving distance between cities
19. What is the shortest path problem concerned with?

20. How does the lecture 10 characterize dynamic programming in terms of direction?
→ It can be thought of as a bottom-up approach

→ When subproblems are not independent
23. How is a path in a graph defined in the lecture 8?

→ Optimization problems
38. What is an adjacency list for vertex i?
→ A linear list of vertices adjacent from vertex i
39. How is the weight of a path calculated?
→ By summing the weights of the path's edges
